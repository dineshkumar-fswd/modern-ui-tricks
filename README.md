# ✨ Modern UI Tricks

A collection of modern UI components, animations, and design techniques built using **HTML**, **CSS**, and **JavaScript**.

This repository is where I recreate and experiment with trending UI designs to improve my front-end development skills and build reusable components for future projects.

---

## 🚀 About

Modern UI Tricks is a growing collection of creative UI elements inspired by modern websites and design trends.

Each component is built from scratch to understand the implementation behind today's beautiful user interfaces.

Whether it's a smooth animation, glassmorphism effect, or interactive slider, every project focuses on clean code, responsiveness, and user experience.

---

- Practice modern front-end development
- Improve HTML, CSS & JavaScript skills
